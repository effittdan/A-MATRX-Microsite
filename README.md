# A-MATRX Micrograft Microsite

Premium React/Next.js microsite for A-MATRX Micrograft, subtly branded as powered by Evologics.

## Local Development

```powershell
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Build

```powershell
npm run build
```

## Notes

- The hero motion is a native canvas animation, so it does not require a third-party animation dependency.
- The orbit graphic section is CSS-based and can be replaced by a Unicorn Studio embed if a production-ready scene is created.
- Copy remains in a conservative HCT/P lane and should be reviewed against current IFU and approved labeling before publication.
